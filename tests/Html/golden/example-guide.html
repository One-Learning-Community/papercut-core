Create and track shipments

Version 2.1 | Updated March 2026

The Parcelpost API lets your store buy shipping labels, book collections and follow parcels without leaving your own system. Every call is plain HTTPS with JSON bodies, and every call can be tried in the sandbox first.

Start with a test key

Test keys create sandbox shipments that never reach a carrier. Switch to a live key only after the checklist on the last page.

Set up

  1. Create an account and open the Developers page.

  2. Copy your test key. It starts with pk_test_ and works only in the sandbox.

  3. Send the request below with your key in the Authorization header.

  4. Store the returned id and poll the tracking endpoint, or register a webhook.

Create a shipment

Request

curl https://api.example.com/v2/shipments \
  -H "Authorization: Bearer pk_test_51Hx0" \
  -H "Idempotency-Key: order-1042" \
  -d service=standard \
  -d 'parcel[weight_kg]=1.4' \
  -d 'to[postcode]=94107'

Response: 201 Created

Webhooks

Parcelpost calls your endpoint when a shipment changes state. Each delivery is signed, so check the signature before you trust the body.

verify.php

<?php

$secret    = getenv('PARCELPOST_WEBHOOK_SECRET');
$timestamp = $_SERVER['HTTP_PARCELPOST_TIMESTAMP'] ?? '';
$signature = $_SERVER['HTTP_PARCELPOST_SIGNATURE'] ?? '';
$payload   = file_get_contents('php://input');

$expected = 'sha256=' . hash_hmac('sha256', $timestamp . '.' . $payload, $secret);

if (!hash_equals($expected, $signature) || abs(time() - (int) $timestamp) > 300) {
    http_response_code(400);
    exit;
}
